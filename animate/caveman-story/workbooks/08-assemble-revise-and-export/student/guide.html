How animators work

Block the meaning, test the action, refine the transition and keep a revision trail. A smooth result still needs readable intention, believable contact and a clear delivery.

Understand before you move

A finished film coordinates story, performance, motion, sound and editing. Completion includes opening the deliverables and checking what the audience actually receives.

The working FLA preserves editability; the rendered movie carries the viewing experience. An editor timeline or successful export command does not prove that the movie plays correctly. Native author tests are separate from a student cold run and from school assessment registration. This package does not claim live progress synchronization.

Assemble the selected actions in story order

IN SHORTGoal → decision → crossing → retrieval → counting reads as one story.
READ ALOUD
DOCUMENT: Caveman story · Workbook 08 · main Scene or named action as stated below
SELECT: Main Scenes Discovery, Crossing and Me_clever.
TOOLS / ROUTE: Scene panel; Library action instances; main timeline.
  1. Use this worked assembly map: Crossing 1–72 = Walk_24 looping for three cycles; 73–84 = a 12-frame Stop; 85–120 = Jump_36; 121–156 = a 36-frame Pickup; 157–192 = a result hold or optional far-bank carrying departure. These authored values can be revised after the animatic check. Discovery uses your selected Think_Point; Me_clever uses the measured recording.
  2. Insert a new Character main-timeline key at every action start and Swap to that action Graphic. Set Jump_36, Stop and Pickup to Play Once/First 1 with exposure exactly covering their local action frames; use Single Frame on the chosen last pose for a hold. Walk_24 alone loops. Main frame = action start + local frame − 1; Jump local 28 therefore lands at Crossing 112.
  3. The jump’s travel is inside Jump_36. Its outer instance stays at the take-off anchor; at Pickup frame 121 place the next action at the landed root position, not back at the take-off anchor. Match the last/first body pose at each hand-off. Remove temporary references, then test the entire movie and check no action loops unexpectedly.

FIXIf an action starts on the wrong internal frame, inspect its Graphic playback and First setting and the parent keyframe where it is placed.

SELECT: Full movie preview, sound temporarily muted in playback.
TOOLS / ROUTE: Test Movie; scene order; frame-by-frame inspection.
  1. Watch for screen direction, prop ownership, foot contact, character scale and background ground height across transitions.

04

Run a focused audience review

IN SHORTThe revision responds to observed audience difficulty, not only personal preference.
READ ALOUD
DOCUMENT: Caveman story · Workbook 08 · main Scene or named action as stated below
SELECT: A playable draft and a viewer who has not followed your timeline.
TOOLS / ROUTE: Playback; three neutral review prompts.
  1. Ask: What does he want? Where did the movement feel unclear or weightless? Did the ending and spoken count agree?
  2. Let the viewer watch without interruption. Record one observation in their words, without collecting personal details.
  3. Choose one high-impact revision. Save a before copy, revise, and replay the same segment.
STEP CHECKLIST
GLOSSARY
critique: Specific observation used to improve a work.
iteration: A cycle of making, testing and revising.
WHYTargeted feedback reveals communication problems that familiarity can hide.
CHECKThe revision responds to observed audience difficulty, not only personal preference.
FIXIf feedback is vague, ask which moment caused it; do not tell the viewer what they were supposed to think.
WORKED EXAMPLE · DIFFERENT OBJECTA user saying “I missed the button” suggests a visibility test, not a total redesign.
STRETCH (AFTER THE CHECK PASSES)Use a second viewer to check whether the repair solved the original problem.

06

Export a playable movie

IN SHORTThe exported file exists, opens in a separate player and includes the full ending.
READ ALOUD
DOCUMENT: Caveman story · Workbook 08 · main Scene or named action as stated below
SELECT: Saved final FLA; entire movie rather than current isolated symbol.
TOOLS / ROUTE: File → Export → Export Video/Media; choose the installed output route.
  1. Save the FLA. Use Export Video/Media for the full movie and select 1280 × 720 with the project’s 24 fps. Inspect the available settings in the installed Animate/Media Encoder workflow.
  2. If Adobe Media Encoder is available, complete the render to a standard playable movie such as MP4/H.264. If that route is unavailable, retain the intermediate or PNG sequence plus WAV, assemble them at 24 fps in an approved editor and export the playable movie there. Keep the source materials; the sequence alone is not the required viewing copy. If no approved render route is available, mark the viewing copy incomplete rather than claiming final delivery.
  3. Do not submit a SWF as the only viewing copy. Name the final playable file clearly and keep it with its source project.
