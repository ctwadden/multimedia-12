SLIDE 03 — Create fourteen independent Graphic definitions  (save your recording as audio/theory/slide-03.mp3)
Separate definitions let you revise one part without unintentionally replacing every limb. Fourteen named Graphic definitions and fourteen part layers exist; selecting an arm does not select the whole Caveman. If several pieces edit together, exit symbol editing and check whether you reused one definition. Duplicate and replace the appropriate instance.

Layer order creates depth; overlap hides seams. A single action container lets the whole performance be staged later. The neutral character has attached joints, a consistent head size and no floating feet. If a limb disappears, check visibility, layer order and scale before importing another copy. If a dark halo appears, inspect the source edge on a light background.

A useful repair demonstrates the cause of a failure, rather than hiding it behind another part. The same rotation produces an attached joint after your repair.
