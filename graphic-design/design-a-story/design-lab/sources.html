Understand the model.

This teacher-created lab demonstrates design relationships. It does not predict attention, feelings or design quality. It produces local practice evidence for teacher review.

Genuine references

  • IKEA Museum: history of the logotype. Local images show the 1951 catalogue and the 1984 blue/yellow mark. They remain unchanged. Historical examples are not current colour specifications.
  • London Design Festival 2025 identity by Domenic Lippa / Pentagram. The selected genuine image shows a typographic thread. The designer’s intentions are not a measured audience response.

Copyright belongs to the respective rights holders. Images are attributed classroom references, not production assets for students’ new advertisements. Keep a source/permission log for your own imagery. No real brand is reconstructed by the editing tools.

What changes—and what stays fixed

Each study starts with a fixed teaching baseline. In comparisons, words and artwork remain the same. Controls change the named relationship. Each episode is a separate controlled experiment; the new brief lets you combine choices. The poster artwork and community briefs are original fictional teaching studies.

  • Composition: relative size, shared edges, gaps, position and repetition. Symmetry is one possible balance strategy. Reading order must be tested with a viewer.
  • Colour: RGB hue/HSB conversions into eight-bit sRGB HEX values. Monochromatic, analogous, complementary and triadic selections use this model, not the traditional RYB wheel or an exact copy of Adobe Color. HSB value differs from perceived brightness and relative luminance.
  • Typography: individual system-font glyph positions. A pair offset affects the first pair; tracking affects every gap in a selected run. Both scale with type size. Leading adjusts baselines. The model requests Georgia with a local serif fallback; it does not claim a festival font or Photoshop Optical kerning.

Readability calculation

The flat text/background test uses the W3C sRGB luminance and contrast formula. It checks 4.5:1 for normal text without rounding the pass decision; qualifying large text uses 3:1. It is not a whole-poster grade or an accessibility certification. Logos have an exception in that guideline. Use actual size, content and viewer feedback too.

Photoshop handoff

Adobe: line and character spacing distinguishes pair kerning, range tracking and leading. Native Photoshop can shape text differently from this browser model.

Adobe: manage swatches documents importing CSS colour definitions through the Swatches panel. The exported CSS contains five named role declarations, not an ASE file. School-version CSS import is not verified. Use manual HEX entry and new swatches if needed. Save, reopen and test your actual Photoshop file. RGB values do not guarantee a matching printed colour.

Adobe Color is an optional professional companion; it is not required to run this lab.

Your evidence and privacy

Your predictions, settings and explanations stay in this browser when local storage works. No names, accounts, API calls, analytics or online submissions are required. Shared devices retain saved work until cleared; export and clear it before another learner uses the browser. If storage is unavailable, the lab works in this tab and says to export. Settings and completion are practice evidence, not achievement grades.

Existing MM12 outcomes 1.4 and 1.5 guide this practice. Actual editable Photoshop work can provide separate evidence for 1.1 and 1.3. This tool does not certify coverage, create new course IDs or submit to Forms, Student OS or the Evidence Map. Your teacher selects the existing submission route.
