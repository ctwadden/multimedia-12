Professional connection

Study the genuine IKEA historical catalogue and current professional identities in the existing teaching gallery. Observe hierarchy, colour, type and context before deciding which relationship can inform your own work. Analyse-only references are not production assets.

Knowledge before controls

A mood board argues for direction; a thumbnail explores an idea; an artboard develops a defined layout. A mask changes visibility; an adjustment changes image relationships. Hierarchy, value/colour and type must help the audience understand this brief.

What this assesses

MM12 image-manipulation outcomes 1.1–1.5: purposeful manipulation, image context, recoverable procedures, design principles and communication. Teacher O/C/P evidence is judged through the same criteria. Knowledge/reflection supports correction. This still-image project does not certify motion, sound or the whole course.

08

Practise a recoverable mask

IN SHORTThe correct mask is selected and the original image can be revealed again.
READ ALOUD
DOCUMENT: Seed-library practice PSD
SELECT: The placed image layer, then its mask thumbnail
TOOLS / ROUTE: File → Place Embedded; Select → Subject; Layer mask; Brush
  1. Open the separate seed-library practice source in a practice PSD. Use File → Place Embedded for a permitted secondary source, confirm placement and rename its layer.
  2. Select the secondary image layer. Use Select → Subject, inspect the selection, then add a layer mask. Inspect the actual edge at 100% and at the intended viewing size.
  3. Click the mask thumbnail before Brush. Set a soft round brush, Opacity 100%, Flow 100%; choose a brush size suited to the edge. Black hides and white reveals. Make a small reversible change, then undo/redo to inspect it.

IN SHORTToggling isolates the intended effect and unrelated areas are retained.
READ ALOUD
DOCUMENT: Practice composite PSD
SELECT: Base image, then adjustment layer/mask
TOOLS / ROUTE: Layer → New Adjustment Layer → Curves; optional Create Clipping Mask
  1. Identify one actual tonal mismatch in the separate practice file. Add a Curves adjustment above the relevant image through Layer → New Adjustment Layer → Curves.
  2. Predict the tonal change before editing. Make one small curve change and toggle the adjustment to compare at the same view. Exact curve values depend on the source; do not copy an unrelated recipe.
  3. If the change should affect only the intended base image, select the adjustment and use Layer → Create Clipping Mask. Refine the adjustment’s mask where needed. Save a version and record the control/result.

READ ALOUD

TOOLS / ROUTE: Type tool → Window → Character / Paragraph
