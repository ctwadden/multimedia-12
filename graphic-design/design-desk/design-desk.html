Colour relationship

The neutral paper/ink roles are outside the hue family. A monochromatic palette uses one hue with value/saturation variations; a small neutral is permitted. Relationships do not make a palette automatically suitable.

Typography & placement

Tracking changes the selected range. This kerning control changes only one letter pair. Leading changes the distance between line baselines. Position uses design units; these controls model layout, not Photoshop menu commands.
