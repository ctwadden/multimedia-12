Three-class assignment

Each class adds new learning

Class A · Diagnose, select and construct

Gallery diagnosis and a short phone-mask preflight lead into source compatibility, Moon selection, Smart Object placement, transform/distort and the first rough composite.

Class B · Make the impossible believable

Isolate the chair, rebuild contact and cast shadows, create the day-for-night grade and paint local moonlight on the chair, supports, seat and ribbon.

Class C · Communicate, test and transfer

Add glow/rim light, complete a believability audit, add a purposeful campaign message, revise after critique and prove one unpredictable live edit.
