Multimedia 12 · Week 1 · Part 1

Understand + prepare

Class 1 · 0–25 min · Follow every step in order. Do not skip the expected-result check.

Before you begin: Open the student ZIP, place it in a named course folder, preserve the originals, and save a versioned working file before editing.
Linear build

Do → inspect → repair

Every visible outcome is taught below. A step is not finished until your screen or evidence matches the expected result.

Step 1

Complete the phone-mask preflight

Course mask laboratory

Hotkey: B · D · X

Expected result
Student hides and restores one edge and explains black versus white
Why this matters
The old assignment becomes retrieval evidence, not repeated production
Warning — common failure
Spending the class rebuilding the phone
Repair it
Stop after the mask explanation and move to the new sources
Step 2

Pass the source-compatibility gate

Chair and Moon files side by side

Hotkey: No required shortcut — use the named menu or panel.

Expected result
Viewpoint, light direction, resolution, scale and colour temperature are annotated
Why this matters
Bad source relationships cannot be repaired by effects
Warning — common failure
Choosing only by subject matter
Repair it
Name one compatibility strength and one predicted problem
Step 3

Create the project and first PSD

File > New/Open; Save As

Hotkey: Cmd/Ctrl Shift S

Expected result
Named folders and MM12_Surreal_Firstname_v01.psd exist
Why this matters
Versioned editable evidence protects the workflow
Warning — common failure
Editing the downloaded source directly
Repair it
Save the PSD before the first edit
Step 4

Select and mask the Moon

Elliptical Marquee > Transform Selection > Select and Mask

Hotkey: M

Expected result
The Moon edge is complete, repairable and free of black fringe
Why this matters
The mask preserves the original source
Warning — common failure
Cutting into the lunar edge
Repair it
Expand slightly, inspect on light/dark, then repair the mask
Step 5

Place as a Smart Object

File > Place Embedded

Hotkey: No required shortcut — use the named menu or panel.

Expected result
Moon arrives above the chair image with a Smart Object badge
Why this matters
Scaling remains reversible
Warning — common failure
Copying a low-resolution preview
Repair it
Place the supplied original source
Student check

Answer before moving on

Checkpoint: Concept thumbnail, compatibility gate, v01 PSD and a rough-composite screenshot with the Layers panel are saved.
Support

Use the supplied chair and Moon files plus the illustrated tutorial; complete one carefully refined Moon edge.

Transfer

Create two valid Moon placements and defend which composition communicates the stronger idea.
