Industry connection

Matchmove and integration.

Almost every effects shot starts with a matchmove artist solving the camera, a lighter matching the sun, and a compositor matching black level and grain. They are three separate jobs in a studio; here you do all three on footage of a place you know.

Knowledge first

Why this works.

Open the theory deck for the narrated version with checkpoint questions. In short:

Parallax gives the camera away

Near and far markers slide differently; from that the solver finds the camera’s path.

One real measurement

A floor and one known distance make every object the right size in the right place.

Read the light before adding any

Shadow direction and length tell you where the sun is. A backlit plate needs dark CG.

Three matches

Black level, softness and grain.

Design principles in the shot

Scale: troopers near, walker far. Contrast: dark shapes against a bright sky. Movement: three speeds at three distances.

02

Detect features and track them

IN SHORTSettings; Detect Features on 1, 140, 270; delete sky markers; track both ways; delete sliders.
READ ALOUD
DOCUMENT: lot_YOURNAME.blend · Movie Clip Editor
SELECT: The clip on frame 1
TOOLS / ROUTE: Detect Features · Ctrl+T (track forwards) · Shift+Ctrl+T (track backwards) · X (delete)
  1. Go to frame 1. In the Track tab, Tracking Settings: Pattern Size 25, Search Size 91, tick Normalize.
  2. Click Detect Features. In the box that appears bottom-left, set Threshold 0.18 and Distance 70. Markers appear on corners and edges.
  3. Click on any marker that sits on sky, cloud or the sun’s glare and delete it (X). Then select all (A) and press Ctrl+T. Blender follows every marker to the end of the clip.
  4. Go to frame 140. Detect Features again and delete the sky ones. With only the new markers selected press Ctrl+T, come back to 140 and press Shift+Ctrl+T to track them backwards. Repeat on frame 270 (backwards only).
  5. Scrub the clip. Every marker should stay glued to its spot. Delete any that slide.

Action by action: what to click (orange boxes), and what you should see

1Detect Features on frame 1.

STEP CHECKLIST
GLOSSARY
Marker: A small box that follows one spot
Parallax: Near things slide faster than far things when the camera moves
WHYOne detection is not enough: things that enter the frame later have no marker. Detecting at the start, middle and end gives the solver points all the way through.
CHECKMore than 60 markers with red and blue tails, spread over near asphalt, the cars and the far tree line.
FIXA marker stops early? That is normal. A marker jumps to a different spot? Delete it.

SELECT: Your tracked markers
TOOLS / ROUTE: Solve tab · Keyframe A / B · Refine › Focal Length · Solve Camera Motion · Clean Up

Match the sun

IN SHORTRead the real shadows; add a Sun in front; Strength 6, Angle 2°; World 0.06; test with a cube.
READ ALOUD
DOCUMENT: lot_YOURNAME.blend
SELECT: The real shadows in the clip
TOOLS / ROUTE: Shift+A › Light › Sun · R (rotate) · Strength · Angle · World › Strength
  1. Look at the clip. The car shadows fall toward the camera and are about as long as the cars are tall. So the sun is in front of us, about 35° up.
  2. Shift+A › Light › Sun. In the top view rotate it so it shines from the far tree line back toward the camera; in the side view tilt it 35° above the ground.
  3. Light properties: Strength 6, Angle 2° (soft edge), colour slightly warm.
  4. World properties: colour pale blue, Strength 0.06. The plate is exposed for the bright sky, so the shade side must stay dark.
  5. Add a cube 1.7 m tall beside the nearest car (in 3D). Render one frame (F12). Its shadow should point the same way and be about the same length as the car’s. Adjust the sun until it does, then delete the cube.

IN SHORTPink feathered solid in Add mode following the engines; Transform on an adjustment layer for the shake; grade; render H.264.
READ ALOUD
DOCUMENT: lot_YOURNAME.aep
SELECT: Your matched comp
TOOLS / ROUTE: Layer › New › Solid · Ellipse mask · Add mode · Layer › New › Adjustment Layer · Effect › Distort › Transform · Composition › Add to Render Queue
  1. Layer › New › Solid, 200 × 200, pink. Draw an ellipse mask on it and feather it 50. Set its mode to Add. Name it Engine glow.
  2. From the first frame the X-wing appears, key the glow’s Position on the ship’s engines every 3–4 frames, and Scale from big to tiny as it flies away. Trim the layer to those frames.
  3. Layer › New › Adjustment Layer, name it Shake. Add Effect › Distort › Transform. Set Scale to 103.
  4. For the 20 frames around the pass-over, key Transform’s Position a few pixels in a different direction on every frame: big moves (10–14 px) as the ship passes, shrinking to nothing.
  5. Add one more adjustment layer with a little Contrast and Vibrance. Composition › Add to Render Queue › H.264 › Render. Name it lot_YOURNAME.mp4.
