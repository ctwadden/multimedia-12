Key ideas

  • Transforming and Scaling assets to fit background proportions
  • Blending Modes and Opacity adjustments for depth and distance realism
Vocabulary
Quick Selection Tool — A tool used to quickly paint over areas to create a selection boundary based on automatic edge detection.
Layer via Copy — A command that places a selected area of an image onto its own brand-new independent layer.
Lasso Tool — A manual selection tool used to draw freehand selection borders to add or subtract from existing selections.
Blending Mode — A setting in the Layers panel that determines how a layer's pixels blend with the pixels of layers underneath it.
Layer Opacity — A transparency setting that controls how see-through a layer is, helping create the illusion of distance.
Move Tool — A tool used to drag and position image tabs, layers, and graphic assets across the canvas.
