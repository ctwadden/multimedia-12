Your production brief

You are producing a studio launch concept for THE STUDIO / FOOTWEAR EDIT. The product must feel supported by a display block, not pasted onto a poster. The layout needs a large editable headline, restrained supporting copy, and two controlled colour treatments.

Deliver: one repaired product PSD, two layered ad PSDs, two 1200 × 900 PNGs, and a brief practical revision. This is the second build in the ten-class boot camp—not a separate ten-class unit.

Save the main source image

One source; the rest is built.

You construct the studio backdrop, accent disc, three-face display block, shadows, lettering and action panel. No paid stock, external fonts, plug-ins or generative credits are needed to complete the steps.

Use installed Arial Regular/Bold. A similar installed sans serif is acceptable. Reference lettering uses a compatible substitute; do not distort letters to chase an exact match.

The source is a prepared crop of an AI-generated footwear concept, not a real product photograph. Visible decorative marks do not imply a genuine product, collaboration or endorsement. The supplied copy makes no performance claims.

Production note: the illustrated reference uses the same supplied asset. The full workflow has not been executed end-to-end in Photoshop here; selection results and brush repairs will vary. No native finished exemplar PSD is supplied. The teacher guide records the checks still needed.

Read the targets before clicking

DOCUMENT prevents editing the wrong file. SELECT names the active layer or thumbnail. TOOLS / ROUTE shows the command. Why / Check / Fix explains the purpose and the recovery. Save at the checkpoints.

Coordinates start at each canvas’s upper-left. Source steps use 800 × 650; the advertisement uses 1200 × 900. Windows Ctrl/Alt corresponds to Mac Cmd/Option where paired. Use menu routes when shortcuts differ.

What is new after Below the Surface?

New: deliberate sampling with three retouching brushes; Color Range; two different mask purposes; shaped contact shadows; outline type using Fill versus Opacity; controlled colourway changes.

Class 4 / 60 minutes

Prepare the product. Preserve the details.

Steps 1–8 · source repair, clean edges, recoverable masks and a new ad document.

01

Open the product job and protect the source

DOCUMENT: Source / 800 × 650
SELECT: Source image layer
TOOLS / ROUTE: File > Open; File > Save As; Window > Layers
  1. Extract the ZIP. Open __DROP_ASSET_A002__, not the finished reference. The prepared source is 800 × 650 pixels. It contains three deliberately added repair marks.
  2. Choose File > Save As. Save on your computer as Lastname_Sneaker_Prep.psd. Keep the source PNG untouched. Keep Layers enabled when the option appears.
  3. If the opened layer is called Background and shows a padlock, click that padlock to make it a normal pixel layer. Rename it Source. Open Window > Layers and Window > Properties. Turn View > Rulers on; right-click a ruler and choose Pixels.
  4. Use Ctrl+0 / Cmd+0 to fit the image. Zoom in to examine marks A, B and C on the repair map. The coordinates refer to the source canvas, not your monitor.
  5. Click the New Layer button at the bottom of Layers. Name the blank layer Retouch and leave it selected above Source. Do not paint on Source.
WhyThe preparation file is a reusable product asset. Separate repairs let you compare your decisions with the original without relying on History.
CheckTwo layers: Retouch above Source. The three marks are visible; no repair has been applied yet.
FixA Smart Object opens instead of a pixel source? Close it and use File > Open on the supplied PNG. Do not place the PNG into the final ad yet.
Method references: A1, B1
02

Remove a small spot with automatic sampling

DOCUMENT: Sneaker_Prep.psd
SELECT: Retouch PIXEL thumbnail
TOOLS / ROUTE: Spot Healing Brush (J group)
  1. Zoom to 200–300% around mark A, near source x536, y360. It is the beige circular speck on the forefoot, not the shoe’s existing knit texture.
  2. Click and hold the J tool group; choose Spot Healing Brush. Set Type: Content-Aware, Mode: Normal, brush Size: 15 px, Hardness: 70%. Turn Sample All Layers on.
  3. Confirm that Retouch is selected. Click once on the centre of the speck. The brush should cover the mark plus a thin margin of surrounding knit.
  4. Toggle the Retouch eye off and on. The spot should disappear while the surrounding threads remain believable. Undo and try a slightly smaller brush if the repair becomes a smooth blob.
  5. Return to 100% zoom to judge the repair at a normal viewing size. Save. Do not scrub across the whole toe.
WhySpot Healing chooses nearby source information for you. A small isolated speck is a sensible place to use that speed.
CheckThe unwanted dot has gone; no large soft patch or repeated dark hole replaces it. The change is visible on Retouch, not Source.
FixNothing happens on the blank layer? Enable Sample All Layers. The wrong detail disappears? Undo, zoom closer, and reduce the brush diameter.
Method references: A1, B1
03

Choose your own sample for the thread repair

DOCUMENT: Sneaker_Prep.psd
SELECT: Retouch PIXEL thumbnail
TOOLS / ROUTE: Healing Brush (J group); Alt-click / Option-click
  1. Locate mark B around x425, y393: the short pale zigzag crossing dark mesh. Switch from Spot Healing to Healing Brush in the same tool group.
  2. Set Mode: Normal; Source: Sampled; brush Size: 12 px; Hardness: 50%; Aligned: on; Sample: Current & Below; Diffusion: 2 where available.
  3. Alt-click / Option-click an intact patch of similar mesh roughly 25 px above B. Avoid a lace, seam, coloured panel or the white sole. Release Alt / Option.
  4. Paint along the unwanted thread in two or three short strokes. Watch the sampling cross: it must not move onto a different material. Resample when necessary.
  5. Compare the repaired texture with nearby mesh and toggle Retouch. Undo the latest stroke if it introduces a pale halo. Save when the material reads consistently.
WhyYou choose where Healing Brush obtains texture; Photoshop blends the repair with its surroundings. The sample should match the material and lighting.
CheckThe pale thread is removed without flattening the weave or borrowing white pixels from the sole.
FixA message asks for a source? Alt-click / Option-click first. A dark or pale halo appears? Sample farther from a material boundary and use a smaller stroke.
Method references: A2, B1
04

Rebuild the pale sole with Clone Stamp

DOCUMENT: Sneaker_Prep.psd
SELECT: Retouch PIXEL thumbnail
TOOLS / ROUTE: Clone Stamp (S); sample Current & Below
  1. Locate mark C near x491, y451: the added dark horizontal scuff on the pale midsole. Select Clone Stamp, not Pattern Stamp.
  2. Set Size: 10 px, Hardness: 60%, Mode: Normal, Opacity: 100%, Flow: 100%, Aligned: on, Sample: Current & Below.
  3. Alt-click / Option-click a clean patch on the same pale band, slightly left of the mark. Keep the source at the same distance from the band’s edge so the texture and brightness match.
  4. Cover the scuff with short strokes. Resample from a second nearby point if the pattern repeats. Do not copy the green outsole over the pale band.
  5. Toggle Retouch and inspect all three repairs at 100%. Save. In your own words: which tool made you choose a source point, and why was that useful?
WhyClone Stamp copies pixels directly. It gives you control when automatic blending borrows the wrong colour or softens an important edge.
CheckA, B and C are removed. The sole still has a continuous boundary and its original speckled material, not a large featureless patch.
FixThe repair copies the green sole or stitches? Undo and resample from the pale band. A repeated spot appears? Resample before the next stroke.
Method references: A3, B1
05

Make a selection of the whole shoe

DOCUMENT: Sneaker_Prep.psd
SELECT: Source PIXEL thumbnail; repairs remain visible
TOOLS / ROUTE: Object Selection; Quick Selection
  1. Click Source. Choose Object Selection from the W tool group. Use Rectangle mode; leave Sample All Layers off for this initial silhouette selection.
  2. Drag a loose rectangle from approximately (115,155) to (685,495). Include the pull tab, tongue, laces, toe and entire outsole.
  3. Inspect the outside boundary at 200% zoom. Switch to Quick Selection with a brush around 15 px to add missing product areas. Hold Alt / Option to subtract background.
  4. Do not remove the dark opening inside the collar: it is part of the shoe, not a hole through which the studio background should show.
  5. Leave the selection active. Do not press Delete, rasterize a mask, or use a generated replacement product.
WhyA silhouette mask must retain the product’s manufactured shape. Automatic selection is a starting proposal, not proof that every edge is correct.
CheckThe selected area contains the complete shoe rather than the rectangular source photograph. Check the pull tab and the thin pale sole carefully.
FixAutomatic detection is unavailable? Use Quick Selection to build the silhouette in several short strokes. Use the Lasso with Alt / Option for a small unwanted background area.
Method references: A4
06

Refine a manufactured edge—not hair

DOCUMENT: Sneaker_Prep.psd
SELECT: The active shoe selection
TOOLS / ROUTE: Select > Select and Mask
  1. Choose Select > Select and Mask. Set View to On Black first so pale background fringes are visible. Zoom to 100–200%.
  2. Use starting values: Radius 0 px, Smart Radius off, Smooth 1, Feather 0.3 px, Contrast 15%, Shift Edge −3%. Leave Decontaminate Colors off.
  3. Compare the heel, toe and sole on both On Black and On White views. Reduce the negative Shift Edge if it trims the pale sole. These are starting values, not a promise that every edge needs them.
  4. Use the ordinary Brush inside Select and Mask for a missed solid piece. Do not brush the entire shoe with Refine Edge Brush: this subject is mostly solid manufactured edges.
  5. Choose Output To: Selection and click OK. The marching ants should return. Keep the selection active for the next step.
WhyA tiny edge adjustment can remove background fringe. Large feathering would make the product look soft or translucent.
CheckThe outline remains crisp, the pale sole has not been eroded, and the output is still an active selection.
FixThe result loses detail? Reduce Smooth or Shift Edge before accepting it. A very soft halo? Reset Feather near zero and compare at 100%.
Method references: A5
07

Mask the photograph and its repairs together

DOCUMENT: Sneaker_Prep.psd
SELECT: New SHOE CUTOUT group, then its MASK thumbnail
TOOLS / ROUTE: Layer > Group Layers; Layer > Layer Mask > Reveal Selection
  1. With the selection still active, select Retouch and Source together in Layers. Choose Layer > Group Layers or Ctrl+G / Cmd+G. Name the group SHOE CUTOUT.
  2. Confirm the group itself is active. Choose Layer > Layer Mask > Reveal Selection. The mask belongs on the group so it controls both Source and Retouch.
  3. Choose Select > Deselect. The former grey background should now be transparent. If a grey rectangle remains, expand the group and check that no unmasked source layer sits outside it.
  4. Click the group’s mask thumbnail. With Brush B, Size 8–15 px, Hardness 80%, Opacity 100%, Flow 100%, paint black to hide a small background remnant or white to restore a missing solid edge.
  5. To inspect against two backgrounds, temporarily create a Solid Color fill below the group, test dark and pale colours, then hide that test layer. Save the prep PSD with transparency outside the shoe.
WhyOne group mask keeps the repair strokes and the original photograph together. It also lets you restore hidden material without undoing later steps.
CheckSHOE CUTOUT contains Source and Retouch. Its mask controls the silhouette; the original pixels remain recoverable.
FixBlack paint appears on the photo? Undo and select the mask thumbnail. Repairs remain outside the shoe? The mask is probably on Source instead of the whole group.
Method references: A6
08

Start the advertisement with a clear document size

DOCUMENT: New ad / 1200 × 900
SELECT: New empty advertisement document
TOOLS / ROUTE: File > New; Save As; View > Guides > New Guide
  1. Choose File > New. Set Width 1200 px, Height 900 px, RGB Color, 8 Bits/Channel, 72 pixels/inch, white background and sRGB IEC61966-2.1 where available. Turn Artboards off.
  2. Save locally as Lastname_Drop_Day_Teal.psd. Keep the prep PSD open in its own tab; they are different working documents.
  3. Open Layers, Properties and Character from Window. Turn rulers on and set their units to Pixels. Disable Move tool Auto-Select so layer targeting remains deliberate.
  4. Add vertical guides at 64 px, 580 px and 1136 px, and a horizontal guide at 764 px. Use View > Guides > New Guide for each position.
  5. The left area is for copy; the right is for the shoe and its display. Save, then stop here for the end-of-class check.
WhyThis is a screen-size launch graphic with an intentional reading area. The fixed canvas lets the following placement instructions refer to real locations.
CheckThe ad is a blank 1200 × 900 document. The prepared shoe is saved separately with an editable cutout and repairs.
FixYou see a shoe instead of a blank canvas? Select the new ad tab. Do not use Image Size on the prep document to create the ad.
Class 5 / 60 minutes

Construct a display. Make the shoe belong.

Steps 9–16 · shape construction, deliberate contact, selective colour and clipped adjustments.

09

Build the studio background and floor

DOCUMENT: Drop_Day_Teal.psd
SELECT: Above Background, outside any group
TOOLS / ROUTE: Gradient Fill; Rectangle Tool in Shape mode
  1. Choose Layer > New Fill Layer > Gradient and name it Background gradient. Use two opaque colour stops: 0% #d3e2de and 100% #edf4f1; Style Linear, Angle 90°, Scale 100%. The upper area should be lighter.
  2. Choose the Rectangle Tool (U group). Set mode Shape, Fill #e7ece8 and Stroke None. Draw a rectangle from (0,764) to (1200,900), or enter X 0, Y 764, W 1200, H 136 in its Properties.
  3. Name the shape Floor. Keep the background gradient and floor separate. The floor is a pale studio surface, not a painted shadow.
  4. Select both new layers and group them as 01 BACKDROP. Leave the original locked Background outside the group.
  5. Reopen the gradient by double-clicking its fill thumbnail, then cancel. This confirms that its colours are still editable. Save.
WhyA quiet studio setting leaves room for both a complex product texture and a large headline. Separate layers keep later colour changes controlled.
CheckA very light vertical gradient fills the canvas; the floor starts at y764. There is no distracting horizon through the main product area.
FixThe gradient is reversed? Turn Reverse on in the fill dialog. A selection limits the fill? Deselect and recreate that fill layer.
Method references: A7, A8
10

Add the accent disc and a soft display shadow

DOCUMENT: Drop_Day_Teal.psd
SELECT: 01 BACKDROP; then a new layer ABOVE it
TOOLS / ROUTE: Ellipse Shape; Elliptical Marquee; Smart Filter
  1. Inside 01 BACKDROP, create an Ellipse shape named Accent disc. Set Fill #75c9be, Stroke None, X 652, Y 233, W 490, H 490. Keep it above the gradient and below Floor.
  2. Collapse 01 BACKDROP. Create a new blank pixel layer above it called Ground shadow. Choose Elliptical Marquee, Feather 0, and drag approximately from (596,759) to (1210,815); the last part extends beyond the canvas.
  3. Choose Edit > Fill > Black, Normal, 100%. Deselect. Right-click Ground shadow and choose Convert to Smart Object.
  4. Choose Filter > Blur > Gaussian Blur, Radius 20 px. Set Ground shadow blending mode to Multiply and layer Opacity to 22%.
  5. Keep this shadow below all display-block faces. It supports the display block, not the shoe. Save.
WhyThe disc creates a clear colour relationship with the product. The large ground shadow stops the display block from looking detached from the floor.
CheckA mint disc sits on the right. The ground shadow is very soft and low on the canvas, with no hard black ellipse.
FixA filled ellipse covers the whole design? Undo and check that only your marquee was selected before filling. A black shape looks too heavy? Check layer opacity, not brush opacity.
Method references: A8, A9
11

Construct a three-face product display

DOCUMENT: Drop_Day_Teal.psd
SELECT: Three new PIXEL layers above Ground shadow
TOOLS / ROUTE: Polygonal Lasso; Edit > Fill; grouping
  1. Create a pixel layer named Front. Set the foreground colour to #bac8c4. With Polygonal Lasso, Feather 0 and Anti-alias on, click (610,621), (1125,687), (1125,789), (610,723), then the first point. Fill Foreground Color and deselect.
  2. Create Side above Front. Use #8ea7a2. Make a closed polygon through (1125,687), (1195,638), (1195,740), (1125,789). Fill and deselect.
  3. Create Top above Side. Use #f0f5f1. Make a closed polygon through (610,621), (1125,687), (1195,638), (693,578). Fill and deselect.
  4. Zoom in on shared corners. Adjacent faces should meet without gaps. Small coordinate differences can be corrected on the relevant face; do not merge the three faces.
  5. Group Top, Side, Front and Ground shadow as 02 DISPLAY. Top is the lightest face; Side is the darkest. Save.
WhyShared corners and different face values make three flat polygons read as one display block. The perspective comes from the shape relationships, not an old 3D feature.
CheckA coherent block sits under the future shoe. Top, Front and Side remain separate, named layers.
FixA triangle appears instead of a four-sided face? Undo, deselect and repeat the four corners. A crack appears? Inspect which shared vertex is misplaced before editing.
12

Place the prepared shoe without flattening your work

DOCUMENT: Drop_Day_Teal.psd
SELECT: Above 02 DISPLAY, outside that group
TOOLS / ROUTE: File > Place Embedded; Edit > Free Transform
  1. Confirm that Lastname_Sneaker_Prep.psd is saved with its background test layer hidden. In the ad tab, select the collapsed 02 DISPLAY group.
  2. Choose File > Place Embedded and select your own prep PSD. Confirm placement and rename the new layer Shoe master. This is not the supplied teacher cutout.
  3. Choose Edit > Free Transform. Enable the reference-point control and choose its centre point. Set the source canvas to 800 × 650 px; keep the width/height link on. Enter X 900 px and Y 520 px; Angle 0°.

  5. Group Shoe master as 03 PRODUCT. Keep the whole group above 02 DISPLAY. Save.
WhyPlacing the preparation PSD keeps a reusable embedded source. It separates repairing the product from designing the advertisement.
CheckOnly the shoe appears, not the old studio rectangle. Shoe master has a Smart Object icon and is positioned on the display’s top face.
FixA grey rectangle appears? Hide the test fill in the prep file, save, then use Layer > Smart Objects > Replace Contents. If transform bounds trim transparency, keep the visible shoe about 541 × 310 px, with top-left near (630,365); do not stretch it to 800 px wide.
Method references: A10
13

Add a broad ambient shadow beneath the shoe

DOCUMENT: Drop_Day_Teal.psd
SELECT: New layer inside 02 DISPLAY, ABOVE Top
TOOLS / ROUTE: Elliptical Marquee; Free Transform; Gaussian Blur
  1. Expand 02 DISPLAY and click Top. Add a blank pixel layer named Ambient shadow. Do not place it in 03 PRODUCT.
  2. With Elliptical Marquee, Feather 0, draw from approximately (646,618) to (1150,672). Fill Black and deselect.
  3. Convert the layer to a Smart Object. Use Edit > Free Transform; rotate about 8° clockwise so the ellipse follows the diagonal top face. Confirm.
  4. Apply Filter > Blur > Gaussian Blur at 18 px. Set blending mode Multiply and layer Opacity to 16%.
  5. Toggle the shadow while watching the shoe’s underside. It should add a broad, soft grounding effect without forming a black stripe. Save.
WhyAmbient shadow is spread out and soft. It suggests the general reduction of light under the object, but it is not enough to establish close contact.
CheckThe effect sits below the shoe and above the top face. It follows the display’s direction and does not darken the laces or upper.
FixThe shoe becomes darker? The shadow layer is above the product. Move it into 02 DISPLAY above Top. A long black oval dominates? Check the 16% layer opacity.
Method references: A9
14

Make contact at the heel and forefoot

DOCUMENT: Drop_Day_Teal.psd
SELECT: New pixel layer ABOVE Ambient shadow in 02 DISPLAY
TOOLS / ROUTE: Brush; brush roundness; layer opacity
  1. Create a layer named Contact shadows above Ambient shadow. Set blending mode Multiply. Set foreground to black.
  2. Choose a Soft Round Brush: Size 155 px, Hardness 0%, Opacity 45%, Flow 100%. In Brush Settings > Brush Tip Shape, set Roundness about 12% and Angle about −8° so the tip is a shallow ellipse following the display.
  3. Click once beneath the heel, around (731,624). Increase Size to 180 px and click once beneath the forefoot, around (1046,663). Keep each mark on the top face and mostly concealed by the sole.
  4. Judge at 100% and then fit on screen. The closest parts of the sole need a small darker contact zone; the curved arch should not receive an equally thick dark line.
  5. Adjust Contact shadows layer opacity if necessary. Reset the Brush tip to a normal round brush before later mask painting. Save.
WhySmall, darker contact zones distinguish a product sitting on a surface from a floating cutout. Different parts of this curved sole do not touch equally.
CheckThe heel and forefoot feel anchored. There is no uniform cartoon outline around the entire shoe.
FixThe ellipse tilts the wrong way? Reverse the brush Angle after checking the preview. Harsh spots? Reduce opacity or hardness; do not keep stacking clicks.
Method references: A11
15

Select the accent colour—not the whole product

DOCUMENT: Drop_Day_Teal.psd
SELECT: Shoe master IMAGE thumbnail
TOOLS / ROUTE: Select > Color Range; sampled colours
  1. Click Shoe master. Ensure no selection is active. Choose Select > Color Range. Set Select to Sampled Colors, Fuzziness initially 55, Localized Color Clusters off and Invert off.
  2. Click a bright lime eyelet on the shoe. Use the + eyedropper or hold Shift to add the lime heel stripe and toe/outsole accents.
  3. Choose the Selection preview in the dialog. White should cover the accent areas; most of the pale sole, grey knit, dark laces and background should stay black. Grey means partially selected.
  4. Add one darker lime sample if required. Reduce Fuzziness if grey fabric or the backdrop becomes strongly selected. Do not choose a threshold solely to match a number.
  5. Click OK and leave the selection active. It is normal that marching ants do not describe every partially selected pixel.
WhyThe colour selection becomes a second, local mask. It has a different purpose from the prep file’s outer cutout mask.
CheckThe bright accent pieces are selected while the neutral shoe materials are mostly protected.
FixThe mint disc is selected? Narrow Fuzziness and resample the original lime on the shoe. We will also clip the adjustment to Shoe master, but the colour mask still needs inspection.
Method references: A12
16

Create the teal colourway and a controlled contrast adjustment

DOCUMENT: Drop_Day_Teal.psd
SELECT: Accent colour ADJUSTMENT thumbnail, then its mask
TOOLS / ROUTE: Layer > New Adjustment Layer > Hue/Saturation; Curves
  1. With the colour selection active, choose Layer > New Adjustment Layer > Hue/Saturation. Name it Accent colour and enable Use Previous Layer to Create Clipping Mask. Confirm. The selection becomes its mask.
  2. In Properties, choose the all-colours control: Master on older panels or the first multicolour circle on newer panels. Set Hue +105, Saturation −8, Lightness 0; Colorize off. The lime accents should become teal.
  3. Click the adjustment MASK thumbnail. Restore Brush Roundness to 100%, Size 8–20 px, Hardness 70%, Opacity 100%, Flow 100%. Paint black over unintended neutral-material changes; white restores a missed intended accent.
  4. Add Layer > New Adjustment Layer > Curves above Accent colour. Name it Product contrast and clip it too. In RGB, add points Input 64 / Output 58 and Input 192 / Output 204. Keep endpoints at 0/0 and 255/255. Set this adjustment’s layer opacity to 40% for a restrained effect.
  5. Toggle each adjustment separately. Only the product should change. Save; finish this class with the shoe, display, shadows and teal accents complete.
WhyThe mask controls which details change, and clipping prevents the adjustment reaching unrelated layers. A restrained contrast adjustment should not destroy material detail.
CheckAccent colour and Product contrast both show clipping indicators above Shoe master. Laces, pale midsole and background stay neutral.
FixThe whole poster shifts colour? Check clipping and the adjustment mask. A mask brush paints a flat colour? Select the mask thumbnail rather than the image or adjustment icon.
Method references: A13, A14, A15

Steps 17–24 · live typography, complete campaign copy, alternate colourway and practical evidence.

17

Build a live, outline headline

DOCUMENT: Drop_Day_Teal.psd
SELECT: New Type layer outside 03 PRODUCT
TOOLS / ROUTE: Type; Window > Character; Layer > Layer Style > Stroke
  1. Collapse 03 PRODUCT. Choose Layer > New > Group and name it 04 HEADLINE. Its folder must be above 03 PRODUCT at the same indentation. With 04 HEADLINE active, choose Type T, click once to make point text, and type DROP.
  2. Use installed Arial Bold, Size 170 pt, Tracking 0, colour #12343c. At 72 pixels/inch, this size is 170 pixels per em. Keep horizontal and vertical character scaling at 100%.
  3. Position the text’s left edge near x60 and its baseline near y305. Use the layout map as the visual target. Commit with the Type checkmark; rename the layer DROP - outline.
  4. Choose Layer > Layer Style > Stroke. Set Size 2 px, Position Outside, Blend Mode Normal, Opacity 100%, Fill Type Color, colour #12343c. Confirm.
  5. In the Layers panel set Fill to 0% but leave layer Opacity at 100%. The letters’ fill disappears while the stroke remains. Do not rasterize the text.
WhyThe thin outline is deliberately quieter than the solid word that follows. Fill and Opacity are not interchangeable when a layer style is present.
CheckDROP remains editable Type. You can see through the letters but their dark outline is visible.
FixThe whole word disappears? Restore Opacity to 100% and reduce Fill instead. A substitute font is wider? Reduce font size modestly; do not squash its horizontal scaling.
Method references: A16, A17

19

Add the studio identity, rule and colour accents

DOCUMENT: Drop_Day_Teal.psd
SELECT: New layers inside 05 COPY
TOOLS / ROUTE: Type; Rectangle Shape; Properties
  1. Create THE STUDIO / FOOTWEAR EDIT in Arial Bold 20 pt, colour #102f37, with left edge x64 and baseline y79. This is fictional campaign copy, not the manufacturer of a real shoe.
