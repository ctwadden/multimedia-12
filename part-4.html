Multimedia 12 · Week 1 · Part 4

Communicate + defend

Class 3 · 70 min · Follow every step in order. Do not skip the expected-result check.

Before you begin: Open the student ZIP, place it in a named course folder, preserve the originals, and save a versioned working file before editing.
Linear build

Do → inspect → repair

Every visible outcome is taught below. A step is not finished until your screen or evidence matches the expected result.

Step 17

Choose the communication pathway

Product ad or social-message brief

Hotkey: No required shortcut — use the named menu or panel.

Expected result
Audience, purpose, message and desired response are written before type is added
Why this matters
Intent prevents decorative copy
Warning — common failure
Adding a random motivational quote
Repair it
Write one audience action or interpretation
Step 18

Build the message hierarchy

Editable type and shape layers

Hotkey: T

Expected result
Headline, support line and optional action read in that order
Why this matters
The image and words must share one focal system
Warning — common failure
Covering the focal image with text
Repair it
Use negative space and no more than two type roles
Step 19

Complete the silent peer test

Five-second review card

Hotkey: No required shortcut — use the named menu or panel.

Expected result
Reviewer records message, focal point and weakest tell without coaching
Why this matters
Received meaning is stronger evidence than explanation
Warning — common failure
Explaining before showing
Repair it
Show silently and record exact words
Step 20

Revise the weakest system

Rubric plus peer evidence

Hotkey: No required shortcut — use the named menu or panel.

Expected result
Before/after proves one targeted technical or communication improvement
Why this matters
Revision converts feedback into learning
Warning — common failure
Adding another effect
Repair it
Repair the named mismatch first
Step 21

Export and defend

Export As plus live teacher challenge

Hotkey: Cmd/Ctrl Option/Alt Shift W

Expected result
sRGB PNG, layered PSD, evidence set and successful unpredictable edit are complete
Why this matters
Process evidence protects authorship and demonstrates transfer
Warning — common failure
Submitting only the final JPEG
Repair it
Run the seven-item submission audit
Student check

Answer before moving on

Checkpoint: Final campaign, before/after, layered PSD, source log, critique evidence and production defence are complete; student can perform one live adjustment.
Support

Use the guided Moon build and one provided message frame; prioritize a coherent scene over extra effects.

Transfer

Replace either source with a new rights-safe asset and explain the geometry, light and message decisions that had to change.
