Multimedia 12 · Week 1 · Part 3

Light + integrate

Class 2 · 70 min · Follow every step in order. Do not skip the expected-result check.

Before you begin: Open the student ZIP, place it in a named course folder, preserve the originals, and save a versioned working file before editing.
Linear build

Do → inspect → repair

Every visible outcome is taught below. A step is not finished until your screen or evidence matches the expected result.

Step 12

Paint moonlight on chair back and supports

Clipped Curves/Color Balance with black mask

Hotkey: B · X

Expected result
Camera-left/upward faces receive controlled cool light
Why this matters
Local response makes the Moon causally present
Warning — common failure
Brightening the entire chair
Repair it
Paint only planes facing the Moon at low opacity
Step 13

Add light to seat and ribbon

Polygonal Lasso plus local adjustment masks

Hotkey: L

Expected result
Seat reads lit from above and ribbon keeps dimensional twists
Why this matters
Small local cues make lighting physical
Warning — common failure
Washing every plane evenly
Repair it
Vary brightness by surface angle
Step 14

Run the four-control simulator

Composite believability simulator

Hotkey: No required shortcut — use the named menu or panel.

Expected result
Student tests direction, softness, exposure and colour and records the weakest cue
Why this matters
Isolation helps diagnose one variable at a time
Warning — common failure
Treating the simulator as a score
Repair it
Use it to form a claim, then verify in the PSD
Step 15

Add controlled glow and rim light

Moon layer effects plus masked light layer

Hotkey: No required shortcut — use the named menu or panel.

Expected result
Glow supports the source without outlining every object
Why this matters
Light falloff reinforces depth
Warning — common failure
Using a large uniform outer glow
Repair it
Reduce size/opacity and mask spill
Step 16

Run the eight-system audit

Edges, geometry, value, colour, light, shadow, texture, interaction

Hotkey: No required shortcut — use the named menu or panel.

Expected result
One strongest system and one weakest system are named
Why this matters
Diagnosis directs revision
Warning — common failure
Calling the image finished because it looks cool
Repair it
Test each system separately
Student check

Answer before moving on

Checkpoint: Final campaign, before/after, layered PSD, source log, critique evidence and production defence are complete; student can perform one live adjustment.
Support

Use the guided Moon build and one provided message frame; prioritize a coherent scene over extra effects.

Transfer

Replace either source with a new rights-safe asset and explain the geometry, light and message decisions that had to change.
